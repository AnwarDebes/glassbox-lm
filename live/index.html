Tsetlin Machine research · the count floor

Every next word,
a sum of votes you can read.

Before a language model made of logical clauses can matter, it has to beat a model that only counts. This page builds that model in your tab: it reads ten public-domain books, counts every pattern of up to five words, and predicts the next word as an exact sum of clause votes, each one traced back to the pages it was counted from.

1 · the glass box

Write, and read why it guesses what it guesses

Each guess is a vote. A pattern it counted in the books, like “the last two words were best of”, is a clause: it fires when your text ends that way and votes for the words that came next. Your own text is a second source: a memory of what you have written so far.

    3 · the floor, measured in this tab

    How surprised is it by chapters it never counted?

    Nineteen chapters were held out and never counted. The page scores every word of them, once with each amount of context and once with the memory of the chapter so far. Lower is better: perplexity is the number of words it is, on average, choosing between.

    Read this before quoting a number

    • A reimplementation, checked. The model on this page is the CVTM-core of the study (section 11 of its engine specification) written again in JavaScript. A test runs the study's own Python code on the same tokens: every probability agrees to within 4 × 10−15.
    • A different corpus. Ten public-domain books, lowercase words, 678,041 counted tokens. The study used WikiText-103 with byte-level subwords. Perplexities here are per word and are not comparable with its bits per byte.
    • No Tsetlin Machine runs here. This is the floor the study measured its Tsetlin Machine language model against. That model stayed above it, which here means worse.
    • Fitted the study's way. The weights of the memory come from the study's MAP-EM on 14 training chapters, chosen by the study's residue rule (10 percent instead of 1, because there are 208 chapters instead of 28,472 articles).
    • New words. A word the books never use gets one of 64 slots: the counts have never seen it, the memory can learn it from your text.
