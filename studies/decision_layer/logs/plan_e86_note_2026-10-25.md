  the job's second run adds another.
- **The change:** for a STAR tag and seed, rows written at or before this note's freeze are set aside and printed with
  no rule; the check needs exactly one row written after the freeze, with its preds file, and applies every check of
  the plan to it. Without this note's freeze record the full check refuses. The dry mode, MultiWOZ and ABCD are
  unchanged.
- The set-aside row is printed beside the new row of the same tag and seed. The job's code and seed are the same, so
  a difference of +0.00 shows a reproducible path; any other difference is reported and explained before the e86
  result is used.

  freeze" now uses an ABCD row, because for STAR such a row is set aside first.
