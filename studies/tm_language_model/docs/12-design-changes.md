# 12 Log of design changes

This page lists every point at which the study departs from its initial design or from one of its own earlier design decisions. Each row gives what the initial design said, what holds now, why, and the evidence. Code and documents cite a row as `docs/12 <id>` (for example docs/12 F23), so the ids and their order are fixed. The log has 90 rows: A1 to A12, B1 to B15, C1 to C19, D1 to D9, E1 to E6 and F1 to F29.

Line references such as `tm.py:961` are to the vendored GraphTM master c6129e14 (`third_party/GraphTsetlinMachine/GraphTsetlinMachine/`) unless another package is named. A run is cited as `results/<run id>`. The measured values are on the results page ([results.md](results.md)), and the run folders themselves are not distributed with the repository. The labels in square brackets (measured, derived, stated, unverified, verified in source, verified in paper) are the evidence labels of the docs index ([00-README.md](00-README.md)). "Protocol rule N" is rule N of the research protocol ([research-protocol.md](research-protocol.md)), "docs/13" is the pre-registration ([13-preregistration.md](13-preregistration.md)), and an evidence entry "design decision" refers to the design decisions of 2026-09-19, from which the milestones of docs/04 come.

None of the changes relaxes the evidence rules of the research protocol: every number stays labelled, nothing is claimed without a log under `results/`, seeds stay deterministic, kernel changes need tests, and all kill criteria of the initial design are kept (C19).
