# Hash table

Several records of the studies pin files by SHA-256: configs pin source files, a hash file pins the
scripts and data of a frozen analysis, run records hold the hash of the pre-registration, and a result
document quotes the hashes of two patched files. Some pinned files were reworded for publication, in
comments, docstrings, message strings and absolute path constants only. This table gives, for every pinned file that is
part of the repository, the SHA-256 as registered and the SHA-256 of the file as published. Where the two
differ and the pin itself is a file of the repository, the pin was replaced by the published value, so
that the checks in the code still compare equal values.

all 319 run records of hierarchical_tm. The published copy differs in wording only; the note at the top
of the file says what was edited. Ten earlier revisions, recorded by 249 run records, were not retained.
