# Final report

This folder holds the final report of the project in three parts. `final-report.md` is the report itself, in ASCII Markdown; it is the source of the PDF, and each of its tables and figures names the file of the repository that its numbers were read from. `figures/` holds the five figures as plain SVG files with real text and no bitmap, drawn by a script from the same numbers. `glassbox-lm-final-report.pdf` is the same text set for print: A4, 16 pages, with bookmarks and a text layer that can be searched. The PDF was built from the Markdown file by a script, in four steps: the title block (title, author, affiliation, date, repository) is read from the head of the file; the body is converted to HTML with Python-Markdown and given a print style sheet, with the figures as vector drawings and the fonts Noto Serif, Noto Sans and DejaVu Sans Mono; the page is printed to A4 with headless Chrome, which also sets the page numbers; and pypdf writes the bookmarks from the headings and reduces the document information to the title and the author. Nothing is edited by hand between the Markdown file and the PDF, so the PDF holds the text of the Markdown file word for word, next to its title page, its page footers and the labels of the figures. The build scripts are not part of the repository.
